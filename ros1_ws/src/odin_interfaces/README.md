# odin_interfaces

Placeholder package for ODIN1 sensor hardware drivers.

When deploying on the real Unitree Go2 with ODIN1 LiDAR, this package will contain:
- ODIN1 LiDAR ROS driver node
- Camera driver node
- IMU driver node
- Calibration tools

For simulation, `sim_bridge` handles all sensor data via TCP from Isaac Sim.
