# Phase 9

## 目标

把 `Phase 8` 的自动驾驶求解结果变成更适合教学展示的可视化输出。

这一阶段不再扩展 `AL-iLQR` 理论本身，而是把已经得到的优化结果组织成可观察、可对比、可解释的展示材料。

## 本阶段实现的功能

- 增加可复用的自动驾驶场景 builder
- 导出初始轨迹 CSV
- 导出优化后轨迹 CSV
- 导出 `AL-iLQR` outer loop 日志 CSV
- 增加 `phase9_autodrive_visualization_demo`
- 增加 `phase9_visualization_export_test`
- 增加更完整的自动驾驶可视化脚本

## 对应原理

这一阶段没有新的核心 `AL-iLQR` 理论，重点是工程展示层。

它解决的是三个教学问题：

1. 优化前和优化后到底差了什么
2. 车辆在道路和障碍物几何关系里是怎么运动的
3. 外层 augmented Lagrangian 迭代过程中，违反量和罚参数是怎么变化的

因此这里增加的主要不是求解器公式，而是数据导出和图形表达。

## 当前实现的展示内容

可视化脚本现在会在一张图里同时展示：

- 道路中心线与道路边界
- 圆形障碍物
- 初始轨迹与优化后轨迹对比
- 若干关键时刻的车辆矩形姿态
- 优化后速度曲线
- 优化后控制曲线
- 外层 `AL-iLQR` 的 `base cost / violation / penalty` 变化

## 为什么这一阶段要先做静态可视化

动画当然更直观，但静态图更适合先做教学验收：

- 易于保存和比对
- 不依赖额外动画后端
- 一张图就能同时看见几何结果和收敛指标

等展示内容稳定后，再做动画才有价值。

## 验收标准

- 可以导出初始轨迹、优化轨迹和 outer log
- 可以画出自动驾驶场景中的道路、障碍物和车辆姿态
- 可以看到优化前后轨迹差异
- 可以看到外层 `AL-iLQR` 指标变化
- demo、测试和绘图脚本通过
