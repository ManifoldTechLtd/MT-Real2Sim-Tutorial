# Phase 8

## 目标

把前面已经完成的 `AL-iLQR` 求解器接到一个真正的自动驾驶教学场景上。

这一阶段的重点不再是求解器结构，而是建模：

- 车辆怎么运动
- 参考线怎么表达
- 道路边界怎么约束
- 障碍物怎么约束
- 代价函数怎么表达“沿路前进并回到车道中心”

## 本阶段实现的功能

- 增加 `StraightReferenceLine`
- 增加 `LaneTrackingCost`
- 增加 `RoadBoundaryConstraint`
- 增加 `CircularObstacleConstraint`
- 增加 `phase8_autodrive_demo`
- 增加 `phase8_autodrive_test`
- 增加自动驾驶场景绘图脚本

## 对应理论

这一阶段对应的是 `AL-iLQR` 之外的自动驾驶建模层。

求解器本身并没有变，变化的是问题表达：

1. 用运动学自行车模型表达车辆的可行动力学
2. 用参考线定义“理想道路中心”
3. 用 stage cost 惩罚：
   - 横向误差
   - 航向误差
   - 速度误差
   - 加速度和转角控制输入
4. 用 terminal cost 鼓励车辆达到目标纵向位置并回到参考线附近
5. 用 inequality constraints 表达：
   - 控制边界
   - 道路边界
   - 圆形静态障碍物安全距离

从理论角度看，这一阶段是在构造一个“适合交给 `AL-iLQR` 处理的自动驾驶轨迹优化问题”。

## 当前实现的取舍

为了保证教学清晰，这一阶段刻意选择了最小但完整的自动驾驶场景：

- 参考线是直线，不是曲线地图
- 障碍物是单个圆形静态障碍物
- 车辆碰撞模型先用质点中心加安全半径近似
- 可视化先用静态图，不做动画

这些取舍的目的是把重点放在“问题建模如何进入 `AL-iLQR`”，而不是一开始就把地图、车体多边形和复杂障碍物全部堆上来。

## 验收标准

- 单车可以沿参考线向前行驶
- 可以施加速度/转角控制边界
- 可以施加道路边界
- 可以绕开简单圆形障碍物
- demo 和测试通过
