# Phase 13

## 目标

把自动驾驶场景里的车辆碰撞建模从“后轴中心点 vs 圆障碍物”升级成“后轴中心规划 + 多圆车身 vs 圆障碍物”，并把关键车辆参数改成配置文件驱动。

## 本阶段实现的功能

- 新增 `config/vehicle_bicycle_config.ini`
- 新增 `VehicleBicycleConfig` 配置解析
- 新增 `VehicleCircleApproximation`
- 以后轴中心作为运动学自行车模型的规划点
- 用可配置数量的圆近似车身，默认 `2` 圆
- 新增速度约束 `SpeedLimitConstraint`
- 新增 `MultiCircleVehicleObstacleConstraint`
- 新增 `CreateSingleStaticObstacleTestScenario()`
- 新增 `phase13_single_static_obstacle_demo`
- 新增 `phase13_vehicle_geometry_test`

## 对应原理

这一阶段主要处理的是“建模正确性”，不是新的 `AL-iLQR` 数值技巧。

核心思想有两点：

1. 运动学模型里的 `(x, y, yaw)` 代表后轴中心姿态
2. 碰撞检测不再直接用 `(x, y)` 点，而是把车体拟合成多个圆，再和障碍物圆做距离约束

如果第 `i` 个车身圆在世界坐标中的中心是 `p_i(x)`，半径是 `r_i`，障碍物圆心是 `c`，半径是 `r_obs`，那么每个圆对应的不等式约束是：

`(r_i + r_obs)^2 - ||p_i(x) - c||^2 <= 0`

这样做的优点是：

- 约束形式仍然光滑，适合当前 `AL-iLQR` 的有限差分导数
- 可以通过增加圆的数量，提高车身几何近似精度
- 规划点和碰撞几何解耦，符合自动驾驶里常见的后轴中心建模方式

## 当前实现说明

- 配置文件里包含：
  - 轴距 `wheelbase`
  - 加速度范围
  - 转角范围
  - 速度范围
  - 车长、车宽
  - 后轴到车尾距离
  - 碰撞圆数量
- 当前多圆拟合使用等半径圆，圆心沿车体纵向均匀分布
- 默认配置是 `2` 圆，但测试里也验证了 `4` 圆配置可以被正确读取和生成

## 验收标准

- 求解器能够从配置文件读取车辆参数
- 静态圆障碍物场景使用多圆车身碰撞约束
- 测试能验证默认 `2` 圆与覆盖配置 `4` 圆
- 单静态障碍物场景可以完成优化并保持正的碰撞间隙
