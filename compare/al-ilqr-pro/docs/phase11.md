# Phase 11

## 目标

在已有静态障碍物自动驾驶场景上，再向前走一步：支持动态障碍物预测。

这一阶段的重点不是修改 `AL-iLQR` 求解器，而是让约束随时间变化，从而更贴近自动驾驶里的预测规划问题。

## 本阶段实现的功能

- 扩展自动驾驶场景 builder，支持 stage-varying obstacle prediction
- 增加 `CreateDynamicObstacleDemoScenario()`
- 增加动态障碍物预测 CSV 导出
- 增加 `phase11_dynamic_obstacle_demo`
- 增加 `phase11_dynamic_obstacle_test`
- 增加动态障碍物绘图脚本

## 对应理论

这一阶段仍然属于建模层，而不是新的求解器理论。

核心思路是：

1. 在每个 knot point 上，为障碍物提供一个预测位置
2. 把每个时刻的障碍物位置转成该 knot point 的路径不等式约束
3. 再交给已有的 `AL-iLQR` 外层和 `iLQR` 内层统一处理

从优化角度看，这只是把：

- 静态约束 `g(x_k, u_k) <= 0`

扩展成了：

- 时变约束 `g_k(x_k, u_k) <= 0`

这也是自动驾驶轨迹优化里最常见的形式之一。

## 当前实现的取舍

为了保持教学清晰，这一阶段仍然采用最小完整表达：

- 障碍物几何仍然是圆形
- 动态预测先用简单的已知中心轨迹
- 车体碰撞仍然先用中心点 + 安全半径近似

这让重点始终落在“时变约束如何进入 `AL-iLQR`”上，而不是一开始就把复杂感知预测和多边形碰撞全部堆进来。

## 验收标准

- 可以构建带动态障碍物预测的自动驾驶场景
- 优化轨迹能够在时变障碍物约束下保持可行
- 可以导出障碍物预测并画出动态障碍物路径
- demo、测试和绘图脚本通过
